## 📌 About

Welcome to the **JavaScript Guide**!  
This repository provides a clean and practical path to learn JavaScript, using **Node.js** as the backend runtime environment.

Designed for developers of all levels, it focuses on core language mechanics, modern ECMAScript features, built-in Node.js APIs, and clean code principles.

## 🛠️ Getting Started

1. Install **Node.js** (LTS version recommended) from [nodejs.org](https://nodejs.org/).
2. Clone this repository.
3. Open it in **Visual Studio Code (VS Code)**.
4. Run scripts directly via terminal using `node`.

Happy coding 🚀
